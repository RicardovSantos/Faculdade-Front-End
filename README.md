# Faculdade: Front-End

Exercícios de HTML, CSS e JavaScript feitos nas aulas de Front-End do curso de Ciência da Computação. Cada pasta é um exercício independente, sem build e sem dependências.

![Print do Blog Semântico](docs/screenshot-blog.webp)

## O que tem aqui
- `Blog-Semantico`: página de blog com `nav`, `main`, `article` e `aside` (busca, categorias e tags), estilizada com Flexbox. O texto dos posts é de exemplo.
- `Projeto-VendaSeuCarro`: exercício de marcação semântica com `header`, `section`, `article`, `aside`, `figure` e `footer`.
- `aulas`: formulário HTML com campos de texto, seleção e envio de arquivo.
- `introdu-js`: primeiros passos em JavaScript, com tipos de dados, strings e concatenação no console.
- `js-estruturas`: variáveis, funções e `prompt` e `alert`.

## Como fiz
- Marcação semântica em vez de `div` para tudo.
- CSS escrito à mão, sem framework.
- Os scripts de JavaScript são exercícios de console, para praticar a sintaxe.

## Tecnologias
`HTML` `CSS` `JavaScript`

## Como rodar
Baixe o repositório e abra o `index.html` de cada pasta no navegador. Nos exercícios de JavaScript, abra também o console do navegador para ver a saída.
